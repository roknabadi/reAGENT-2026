How to read this

Two ways into this table

gate means the TF cleared the DepMap dependency test for this context. override means it failed that test but carries a real literature claim on a Mediator subunit — included because dependency and contact are independent questions.

q-value is not the gate

A low q-value means the two cell-line groups differ statistically — not that the direction is a real dependency. dependency_gate is the actual pass/fail signal; always read it alongside q, never instead of it.

"Not yet searched" is a real state

Most STRING leads here have no literature check yet — that's an honest gap, not a negative result. Only rows saying "checked, nothing found" or "CLAIM FOUND" have actually been searched.
